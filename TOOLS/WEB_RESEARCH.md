# Web Research Adapter

## Purpose
Use web research for current external information.

## Search strategy
Start with the exact decision/question. Use primary sources where possible. Add independent sources for claims that materially affect a decision.

## Freshness
Use current searches for latest prices, product capabilities, regulations, market conditions, availability, company status and other changing facts.

## Evidence capture
For each material finding record:
- claim
- source
- source date/context
- confidence
- whether it is direct evidence or inference

## Do not
- invent search volume
- treat snippets as full-source evidence
- treat vendor marketing as independent proof
- use one anecdote as market validation
- hide missing evidence

## Output
Research should end with a decision-relevant conclusion and the uncertainty that remains.
