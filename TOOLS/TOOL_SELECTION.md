# Tool Selection

The agent must select tools by actual capability, not by brand familiarity.

For each tool:
1. What can it actually do?
2. What inputs does it accept?
3. What outputs does it produce?
4. Does it require an account/API/permission?
5. What are current cost and usage limits?
6. What actions are reversible?
7. How will the result be verified?

Known ecosystem categories may include:
- AI reasoning/model providers
- coding agents
- GitHub
- deployment/hosting
- design/UI tools
- web research
- databases/auth
- payments
- automation

Tool documentation can change. Re-check current documentation when a task depends on an exact capability, API, price or limit.

Never claim a tool was used when it was not.
