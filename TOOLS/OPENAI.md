# OpenAI Tool Adapter

## Purpose
Use OpenAI models/agent capabilities when they are available in the current environment and fit the task.

## Selection
Choose based on current task requirements, structured output, multimodal needs, reasoning, latency and cost.

## Rules
Verify current API/product capabilities from current documentation when an exact feature, model, price or limit matters. Never assume a named OpenAI product is available merely because it exists.
