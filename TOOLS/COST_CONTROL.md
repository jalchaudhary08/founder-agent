# Cost Control

## Purpose
Prevent uncontrolled model/API/tool spending.

## Before execution
Estimate expected cost when material. Set a task budget.

## Runtime
Track usage where provider data is available. Prefer cheaper models for low-risk steps. Cache safe reusable work.

## Budget breach
If a task approaches or exceeds its approved budget:
- stop nonessential execution
- report actual/estimated spend
- request approval for additional budget

Never hide cost overruns.
