# Decisions

## D001 — Build Founder Agent before full SaaS
Decision: Create a reusable Founder Agent operating system first, then use it to validate and build the first SaaS.
Reason: Reduce repeated work and create a reusable execution layer.
Status: ACTIVE

## D002 — Validate payment before full build
Decision: Seek genuine customer payments before investing heavily in the first SaaS.
Reason: Demand and willingness-to-pay remain the largest uncertainties.
Status: ACTIVE

## D003 — AI Food Label & Nutrition Pack is the current validation candidate
Decision: Use this as the current test product, not as a permanent commitment.
Reason: Clear input/output workflow and identifiable paying business users.
Status: HYPOTHESIS — requires payment validation.
