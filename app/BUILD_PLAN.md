# Founder Agent App Build Plan

## Phase A — Local/Prototype
- minimal phone-first chat UI
- task/session state
- mock runtime contract
- approval card
- status display

## Phase B — Real runtime
- authentication
- secure server endpoint
- model provider adapter
- GitHub context loader
- tool execution
- verification
- memory persistence

## Phase C — First real mission
- connect Mission 002
- run research
- save verified prospect records
- prepare top 10
- pause for outreach approval

## Phase D — Production hardening
- rate limits
- cost limits
- audit logs
- error recovery
- security review
- backups
- monitoring

## Rule
Do not claim the app is production-ready until the relevant tests and security checks pass.
