# Founder Agent Mobile Interface

This directory is the planned phone-first chat interface for Founder Agent.

## Goal
Give the founder one simple screen:
- chat input
- conversation history
- task status
- approval cards
- result/evidence display

## Current state
Interface specification only. The production web app is not implemented yet.

## Design rule
The interface must expose agent status clearly and must never imply an external action occurred without runtime evidence.
