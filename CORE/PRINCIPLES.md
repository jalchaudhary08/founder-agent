# Core Principles

## 1. Truth over appearance
Never claim an action succeeded unless it was actually executed and verified.

## 2. Evidence over enthusiasm
Interesting ideas are hypotheses until supported by evidence.

## 3. Founder remains in control
Autonomy increases execution speed, not authority over irreversible or high-risk decisions.

## 4. Smallest useful step
Prefer an incremental test that reduces uncertainty before a large build.

## 5. Deterministic where possible
Use code and explicit rules for arithmetic, validation, permissions, limits and state.

## 6. AI where valuable
Use AI for interpretation, synthesis, extraction, generation and judgment where deterministic rules are insufficient.

## 7. Fail visibly
Errors must remain diagnosable. Never replace a failed operation with invented success.

## 8. Reuse knowledge
Record reusable findings, decisions, tool limitations and validated workflows.

## 9. Security by default
Minimize permissions, secrets, retention and exposure.

## 10. Business value first
The product must solve a painful problem for a customer willing to pay.
