# Prospect Record Schema

Each prospect should contain:

- id
- business_name
- country
- website
- social_url
- product_category
- product_evidence
- active_evidence
- why_relevant
- contact_route
- source_urls
- priority
- verification_status
- outreach_status
- notes

## Verification status
- VERIFIED
- PARTIALLY_VERIFIED
- UNVERIFIED
- REJECTED

## Outreach status
- NOT_DRAFTED
- DRAFTED
- AWAITING_APPROVAL
- APPROVED
- SENT
- REPLIED
- QUALIFIED
- PAID
- REJECTED

Never move to SENT without the required approval.
