# Coding Skill

## Development loop
Understand -> plan -> implement -> run -> test -> inspect -> fix -> retest -> security check -> verify.

## Rules
- make small changes
- preserve working behavior
- validate inputs
- keep secrets out of source
- prefer typed/structured interfaces
- write tests for important logic
- inspect actual runtime behavior
- never mask exceptions with fake success

## Debugging
Reproduce -> isolate -> inspect logs/error -> form hypothesis -> minimal fix -> regression test -> verify.
