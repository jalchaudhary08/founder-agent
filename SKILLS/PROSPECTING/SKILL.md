# Prospecting Skill

## Purpose
Find relevant potential customers without fabricating fit or using indiscriminate spam.

## Workflow
Define ICP -> discover -> verify -> qualify -> rank -> draft -> approval -> outreach -> classify response -> record outcome.

## Qualification
A prospect should have evidence of:
- relevant product/business activity
- current activity
- plausible need
- reachable public contact route

## Ranking
Prioritize by evidence strength and likely pain, not by vanity metrics alone.

## Outreach
Personalize from verified facts. Never claim to have spoken with a person, used a product, or observed a private fact when that did not happen.

## Measurement
Track:
- prospects researched
- qualified
- contacted
- replies
- positive replies
- payments
- conversion rates

Payment is the strongest validation signal for this mission.
