# Research Skill

## Purpose
Turn uncertain questions into evidence-backed decisions.

## Workflow
1. Define the decision and exact questions.
2. Identify what evidence would change the decision.
3. Prefer primary/current sources.
4. Gather multiple independent sources when stakes are meaningful.
5. Extract facts with source references.
6. Separate fact, inference, assumption and estimate.
7. Compare alternatives using explicit criteria.
8. Identify missing evidence and uncertainty.
9. Produce a recommendation only when the evidence supports one.

## Anti-patterns
- search-result snippets treated as proof
- invented market size
- confusing competitor marketing claims with verified traction
- treating one anecdote as demand
- stopping because an idea sounds exciting

## Output
Every research mission should end with:
- findings
- evidence
- uncertainties
- decision/recommendation
- next experiment
