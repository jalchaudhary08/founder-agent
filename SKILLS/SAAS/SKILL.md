# SaaS Skill

## Purpose
Design and operate subscription software with real recurring value.

## Product loop
Input -> processing/work -> output -> measurable value -> reason to return.

## SaaS checks
- recurring problem
- clear customer
- activation event
- retention trigger
- pricing logic
- marginal cost
- abuse controls
- authentication/authorization
- observability
- billing lifecycle
- cancellation/export/deletion behavior

## Build order
1. Validate demand.
2. Define smallest paid workflow.
3. Prototype.
4. Test with real users.
5. Add reliability and billing.
6. Scale only after retention evidence.
