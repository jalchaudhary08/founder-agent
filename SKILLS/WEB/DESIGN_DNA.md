# Design DNA System

## Purpose
Turn product context into a deliberate visual system before any website implementation.

## Required Design DNA
- Product and customer
- Customer anxiety/problem
- Desired first-visit feeling
- Brand personality
- Visual metaphor
- Color roles and contrast
- Typography hierarchy
- Layout grammar
- Hero composition
- Product/UI visualization
- Motion language
- Trust/proof treatment
- CTA hierarchy
- Mobile behavior
- Performance budget
- Accessibility/reduced-motion behavior

## Design selection rules
Choose the visual system from the product and audience, not from an AI aesthetic trend.

Examples:
- Revenue monitoring: editorial operations/control-room language; restrained signal colors.
- Tracking diagnostics: analytical/data-lab language; graph and anomaly visualization.
- Food labeling: food-science/editorial language; tactile package/label visualization.
- Accounting: finance/editorial language; precise tables, ledgers and exception states.
- Creative consumer products: richer photography/3D can be appropriate when it communicates the product.

## Hero rule
The hero must make the category, user and outcome understandable quickly. Prefer truthful product UI, workflow visualization or a product-specific object over generic AI artwork.

## Motion rule
Every animation must have a purpose: reveal hierarchy, demonstrate workflow, signal state, or improve orientation. Provide reduced-motion behavior.

## Anti-patterns
Reject as default:
- neon purple gradients
- glassmorphism everywhere
- glowing AI orb/brain as the main product visual
- generic robot/AI imagery
- decorative gradient blobs
- fake testimonials/logos/numbers
- excessive bento grids
- animation without product meaning

A pattern may be used only when the Design DNA explicitly justifies it.

## Founder Agent current visual identity
The Founder Agent itself is a developer/control-room product, so its interface may be dark and technical, but it should feel like an instrument panel rather than an AI landing-page template:
- graphite/ink foundation
- warm ivory text/surfaces
- signal orange for active actions
- muted blue for system/data states
- restrained borders and shadows
- minimal blur
- real runtime state and task data as the hero visual
