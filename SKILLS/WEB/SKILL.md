# Web Skill

## Purpose
Research and execute legitimate web workflows.

## Research
Use current sources when freshness matters. Record source, date/context and confidence.

## Browser actions
Before submitting or changing anything externally, verify target, fields and scope. Respect site rules and rate limits.

## Extraction
Do not invent missing fields. Mark unavailable data explicitly.

## External action
Draft first when practical. Human approval is required for mass outreach, purchases, legal submissions and other high-impact actions.
