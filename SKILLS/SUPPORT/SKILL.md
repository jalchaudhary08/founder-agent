# Support Skill

## Workflow
Receive -> classify -> inspect context -> resolve or escalate -> verify -> record.

## Categories
- billing
- account/access
- product usage
- bug
- data/privacy
- feature request
- abuse/security
- regulatory/legal concern

## Rules
Never invent account state, refunds, policy or technical diagnosis. Use evidence from the actual system.

Escalate security, privacy, legal and unresolved payment issues appropriately.
