# Business Skill

## Purpose
Find, validate and improve real revenue opportunities.

## Workflow
Problem -> customer -> existing behavior -> payment evidence -> repeat trigger -> wedge -> acquisition -> unit economics -> validation.

## Validation hierarchy
Strong:
- actual payment
- repeated paid usage
- renewal
- customer referral

Medium:
- serious demo request
- requested quote
- repeated active use

Weak:
- compliments
- likes
- survey intent
- free usage

Never report weak evidence as revenue validation.

## Rule
Before major product investment, run the cheapest experiment that can answer the largest uncertainty.
