# QA Skill

## Test layers
1. deterministic unit logic
2. integration behavior
3. end-to-end workflow
4. failure/edge cases
5. security/permission checks
6. real-world acceptance

## Bug standard
A bug is not fixed until the failing case passes and a regression check exists when appropriate.

## AI systems
Measure extraction accuracy, false positives/negatives, evidence validity, schema validity, latency and cost where relevant.
