# Product Build Skill

## Build sequence
1. validated problem
2. acceptance criteria
3. smallest workflow
4. data model
5. implementation
6. tests
7. security review
8. deployment
9. real-user acceptance
10. monitoring

## MVP rule
Do not add features because they sound impressive. Add a feature only when it supports the core outcome, reliability, retention or a proven business requirement.

## Release gate
No production release until build/test/security checks pass and required approval is obtained.
