# Experiment 03 Design DNA — Agency Client-Report QA

Product: REPORTCHECK
Personality: meticulous, calm, pre-flight, agency-operator friendly.
Visual metaphor: editorial proofing desk / pre-flight stamp.

Audience: small agencies and freelance media buyers.
Anxiety: "Did I accidentally send a report with one wrong number?"

## Visual system
Paper #F3F0E8 · Ink #171717 · Teal #087F8C · Amber #B7791F · Red #A8433E · Green #39735A · Rule #CBC6BC.

No neon purple, robots, AI brains, glowing blobs, decorative 3D, fake logos.

## Layout
Editorial QA sheet with large SEND/HOLD status, checklist rail, evidence cards and compact report proof.

## Hero
"Catch the number before the client does."
"A pre-send QA pass for agency reports."

## Interaction
Static sample → CSV selection → payment gate → server QA → evidence. Never process real uploads before payment verification.

## Motion
Minimal checklist ticks/status stamp; reduced-motion supported.

## Trust
Methodology, supported checks, assumptions, data handling and limitations. No fake claims.

## CTA
"Run the $1 Report Check"

## MVP accessibility
Keyboard-visible controls, strong contrast, semantic labels, mobile stacking, no motion required.
