A modular personal AI operating system for research, business validation, product development and growth.

**Foundation V1: READY**

The repository contains:
- AGENT.md — constitution and operating rules
- CORE/ — orchestration, state machine, principles, approvals, safety, quality and recovery

## Operating philosophy

Truth over appearance. Evidence over enthusiasm. Small verified steps over giant unverified builds.

The agent must never fabricate customers, research, tool access, revenue, completion or test results.
