# Runtime Approval Protocol

When an action requires approval, the runtime must pause.

## Approval request must show
- what will happen
- who/what is affected
- exact scope
- expected cost if any
- final content when communication is involved
- risks
- what has already happened

## Examples
"Drafted 10 outreach messages. Nothing has been sent. Approve sending these 10?"

"Deployment is ready. Tests passed. Production deployment will change the live app. Approve?"

## Never
- infer approval from silence
- reuse an old approval for a materially different action
- claim an action happened while waiting for approval
